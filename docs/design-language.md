# YIIAI 视觉语言（方案 A）

> 形象只有一个头，用在图标、悬浮球、灵动岛、通话页这些「头像位」。没有身体。

## 1. 参考与取舍

- **RikkaHub 兔子**：学方法——只留识别特征、实心块面、同一张脸走遍所有入口、先过小尺寸。
- **用户给的第三张鹿**：学造型——软、团状鹿角、闭眼、口鼻朝左下的侧脸。
- **放弃**：线条耳朵（换背景就看不见）、全身（没有用到的地方）、大鹿角（缩小后只剩一团角）。

## 2. 造型

三块实心形状 + 一张脸，全部画在 512 画布上，实现见 `app/src/main/java/com/yiiai/app/ui/DeerMascot.kt`。

| 部件 | 说明 |
| --- | --- |
| 鹿角 | 两枚小角芽，每枚一个分叉，末端全圆，陶土色 |
| 耳朵 | 两片实心叶耳，横向打开，比脸略深一档 |
| 头 | 3/4 侧脸，口鼻朝左下，没有尖角 |
| 脸 | 一颗鼻头 + 两只眼睛；眼睛是唯一会变的部件 |

所有头像位都自带深色底板 `#17120F`，不依赖下面的背景。48dp 以下自动加粗眼睛和鼻头。

## 3. 色板

| 名称 | HEX | 用途 |
| --- | --- | --- |
| 底板 | `#17120F` | 图标、悬浮球、灵动岛头像底 |
| 身体 | `#F3E4D2` | 头 |
| 耳朵 | `#E9D3BE` | 叶耳 |
| 鹿角 | `#C9866F` | 角芽 |
| 墨 | `#2A1F1B` | 眼睛、鼻头 |

浅色主题下通话页大图没有底板，身体换 `#E9CDB4`、耳朵换 `#DDBB9E`。

## 4. 状态（只改眼睛）

| 状态 | 眼睛 | 附加动作 |
| --- | --- | --- |
| 待命 / 连接 / 聆听 | 闭眼弧线 | 聆听时耳朵竖起 |
| 你在说 | 两颗竖圆点 | 耳朵竖起，光晕随音量 |
| YIIAI 在说 | 向上弯的月牙 | 头微歪，鹿角轻晃 |
| 静音 | 两条横线 | 耳朵垂下 |
| 出错 | × × | 耳朵压低 |

悬浮球和灵动岛头像通过 `deerEyesFor(state)` 同步同一套眼睛。
